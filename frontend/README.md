# Front-end do portfólio

Consulte o [README da raiz](../README.md) para versões, instalação reproduzível, execução, Docker e validação de segurança.

Com Node 24.20.0 e npm 11.19.1, neste diretório:

```sh
npm ci
npm run dev
```

Acesse http://127.0.0.1:8000. Para produção, use o Dockerfile deste diretório, que serve `dist` com NGINX na porta 4173.
